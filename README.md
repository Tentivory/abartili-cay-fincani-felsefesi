# Abartılı Çay Fincanı Felsefesi

Bu repository, dünyanın en ciddi ve aynı zamanda en absürt çay fincanı felsefe simülatörüdür. Çay içmeden önce varoluşunuzu sorgulamanız için tasarlanmıştır. Gerçekten çalışır. Gerçekten.

## Nasıl Kullanılır

1. Python 3 yükleyin (eğer yoksa, çay demleyin ve bekleyin).
2. `python cay_fincani.py` komutunu çalıştırın.
3. Fincanınızla sohbet edin. Cevap vermezse, şeker ekleyin.

## Özellikler

- Rastgele felsefi çay sözleri
- Gerçek zamanlı bekleme (sanki çay demleniyormuş gibi)
- Sonsuz tekrar potansiyeli (ama 5 kezle sınırlı, çünkü çay biter)

## Uyarı

Bu program çayınızı gerçekten demlemez. Sadece düşündürür. Eğer çayınız soğursa, program suçlu değildir.
